# Session: route-namespaces-and-delta-design

## Goal
Two parallel tracks: (1) continued design of the polyglot intent compiler primitives, focusing on event chains, trigger unification, and delta types; (2) building a route-namespace system where TSP namespaces define URL tree structure with compile-time type generation.

## Current State
- 12 base primitives defined (model, scalar, enum, op, namespace, guard, trigger, Input, Self, scope, failureMode)
- side/ namespace killed, merged into flow/ (single-step flow = old side effect)
- guard/ separated from flow/ (temporal distinction: pre-delta vs post-delta)
- Delta as first-class type rejected (leaning toward compiler-internal, author writes triggers not delta patterns)
- Trigger syntax leaning toward intent-readable: @on(Todo.mut.create), @on(Todo.status -> done), @on(external)
- flattenRoutes() implemented and working: namespace tree → typed route model with HTTP method inference
- 12/12 validation fixtures passing
- Multi-agent design consultation completed (5 agents round 1, 3 agents round 2)

## Key Design Decisions This Session

### Primitives reduced to 12
STRUCTURAL: model, scalar, enum, op, namespace
TEMPORAL: guard (pre-op gate), trigger (op-ran | field-moved | external)
FLOW: Input, Self, scope (same|independent), failureMode (rollback|compensate|log)

### side/ merged into flow/
A side effect is a one-step flow. Multi-step orchestration is a multi-step flow. Same namespace, compiler distinguishes by step count.

### guard/ separated (temporal distinction)
Guards gate whether a delta gets produced. Flows react after the delta exists. Different temporal categories, shouldn't be unified.

### Delta rejected as authored type
Author writes triggers (@on expressions), compiler computes deltas internally. "When status becomes done" is intent, Delta<Todo>{field:"status",to:done} is mechanism.

### @onChange + @timing* → single trigger system
@on(Todo.mut.create) replaces @timingOn
@on(Todo.status -> done) replaces @onChange
No Delta<T> wrapper needed

### Todo app modeled with conventions
mut/create, mut/update (put+patch), mut/delete. No setter explosion. Field reactivity via @onChange (now @on).

Written to docs/design/delta-and-causal-chains.md. Key findings:
- Delta as universal primitive (all agents converged)
- Diamond problem and cycles are hard compiler problems
- Production gaps: idempotency keys, partition keys, batch atomicity, schema versioning, DLQ config

- Bookmark manager as toy demo: guard + 1-step flow + N-step flow + onChange + cascade across 5 targets

## Route-Namespace System (implemented)

Namespaces define URL tree. @param("string") marks dynamic segments. CRUD namespace names → HTTP methods. read collapses to parent path.

```
namespace routes {
  namespace users {
    namespace create {}    → POST   /users/create
    namespace read {}      → GET    /users
    @param("string")
    namespace id {
      namespace read {}    → GET    /users/{id}
      namespace update {}  → PUT    /users/{id}/update
    }
  }
}
alias AllRoutes = flattenRoutes(routes);
```

Returns Model keyed by path strings, values have { template: stringLiteral, params: Model, method: stringLiteral }.
