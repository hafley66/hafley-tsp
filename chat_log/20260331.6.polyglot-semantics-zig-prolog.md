# Session: polyglot-semantics-zig-prolog

## Goal
Continued from sync-emitter session. Explored eliminating string emission from Rust emitter via universal expression components, then pivoted to deeper questions about liftable language semantics and type system implementation.

## Current State
- Universal expression components (Let/If/For/Call/Await/Try): fully designed (889 lines), rejected as not worth building. Semantic mismatch between languages makes it more ceremony than value.
- Reactive pipe semantics identified as the actual liftable intersection (functor/combinator vocabulary: map, flatMap, filter, scan, switchMap, etc.)
- TSP's wall identified: has types (nouns) but no arrow types (verbs), can't express A -> B or type-check pipe stage composition
- User decided to learn Zig, potentially for building a type system with pipe semantics

## Key Insights
- The liftable semantic intersection is container + combinator + effect, not imperative statements
- Containers: Option, Result, Array, Iterator, Future, Stream/Observable
- Combinators: map, flatMap, filter, reduce, zip, chain (same across all languages)
- Effects: fallible, concurrent, stateful (intent is universal, mechanism diverges)
- Nobody has built reusable expression-level codegen primitives as a library (15 systems analyzed)
- Haxe/Nim commit to being whole languages. JSII/Protobuf only do declarations. The expression layer is empty.
- RxJS operator canon (~25 operators) as proven vocabulary for pipe semantics
- Pipes are class composition: each operator is a new instance wrapping the previous
- Prolog's unification IS type inference (12 lines for a working inferencer)
- Polonius (Rust borrow checker) is literally a Datalog program
- Type system implementation: Prolog ~150 lines, Lisp ~325, OCaml ~500, Zig ~1100, C ~1800

## Decisions Made
- Expression components: not worth the boiled water
- String emit stays for function bodies, JSX for declarations only
- Pipe/combinator semantics is the interesting design space to return to
- User chose Zig as next learning target
